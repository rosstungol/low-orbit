# Low Orbit

A 3D spaceship flying game built with React Three Fiber.

**Live Demo:** [Low Orbit](https://low-orbit.pages.dev/)

## Tech Stack

| Layer | Technology |
|---|---|
| Language | TypeScript 6 |
| UI | React 19 |
| 3D Engine | Three.js |
| React–Three Adapter | @react-three/fiber 9 |
| R3D Helpers | @react-three/drei 10 |
| Post-Processing | @react-three/postprocessing |
| Build Tool | Vite 8 |
| Linter / Formatter | Biome |

## Getting Started

Install the dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
``` 

## Linter and Formatter

Run the Biome.js linter and formatter:
```bash
npm run lint-format
```
